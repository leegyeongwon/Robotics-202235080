## Description
Code and Screenshot for turn on/off on arduino uno board.

Pin 7 for LED IO.

If you start simulation, The LED will be turned on clearly. After 1000ms, LED will become darker.
Again, after 1000ms, LED will become brighter. This will be repeated eternally. 

## How to execute
1. Go to Tinkeracd:  https://www.tinkercad.com/dashboard
2. Make a curcuit like 'LED_arduino.png'
3. Copy and paste LED_arduino.cpp
4. Execute simulation
